# Physics-Informed Neural Network for Air Pollution Prediction

A machine learning project exploring the use of **Physics-Informed Neural Networks (PINNs)** to model and predict air pollution concentrations by combining environmental sensor data, meteorological information, and physical equations.

## Overview

Traditional machine learning models learn patterns directly from data, but may not account for the physical processes governing those patterns. This project explores a physics-informed approach to modeling PM2.5 (fine particulate matter) concentrations in the Denver metropolitan area.

The model incorporates atmospheric wind conditions and an advection-diffusion equation into a neural network's training objective, encouraging predictions that are consistent with underlying physical principles.

## Methodology

**1. Data Collection and Preprocessing**

- Collected PM2.5 measurements from PurpleAir sensors.
- Retrieved ERA5 meteorological data, including wind velocity and temperature.
- Interpolated environmental measurements onto a geographic grid.
- Processed spatial and temporal features into tensors for neural network training.

**2. Neural Network Architecture**

- Implemented fully connected neural networks using PyTorch.
- Used Fourier feature encoding to capture spatial variation.
- Incorporated wind velocity and temporal information as model inputs.
- Built a data-only baseline for comparison with physics-informed approaches.

**3. Physics-Informed Learning**

Integrated an advection-diffusion equation into the model's loss function:

\[
\frac{\partial C}{\partial t}
+u\frac{\partial C}{\partial x}
+v\frac{\partial C}{\partial y}
-D\nabla^2 C=0
\]

Where:

- \(C\): PM2.5 concentration
- \(u,v\): Wind velocity components
- \(D\): Learned effective diffusion coefficient

The training objective combines a data-fitting loss with a physics-based residual penalty, allowing the network to learn from observations while incorporating physical constraints.

**4. Training and Evaluation**

- Implemented training and validation splits based on time.
- Experimented with physics-loss weighting, dropout, and learning rates.
- Applied weighted sampling to emphasize high-pollution observations.
- Implemented evaluation using MAE, RMSE, and R².

## Getting Started

Clone the repository:

```bash
git clone https://github.com/shors88/pinn-pollution.git
cd pinn-pollution
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Data retrieval scripts require access to the relevant environmental data services. API credentials should be configured securely through environment variables or service-specific credential configuration files.

Training scripts expect preprocessed input tensors generated by the data preparation pipeline.
